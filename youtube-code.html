Код действует несколько минут и только один раз. Не успел — открой ссылку из бота ещё раз. Канал подключал не ты? Перешли код тому, кто прислал ссылку.

В Google нажали «Отмена». Чтобы подключить канал, открой ссылку из бота ещё раз и на экране разрешений отметь все галочки → «Продолжить».

Google вернул ошибку

Код для бота Shorts Factory

Эта страница показывает код для подключения канала YouTube к боту. Открывать её нужно по ссылке из бота: «📺 Каналы» → «⚙️ Настройки канала» → «🔗 Подключить YouTube».

Если ты уже вошёл в Google и видишь это сообщение, код пропал из адреса страницы — открой ссылку из бота ещё раз.
