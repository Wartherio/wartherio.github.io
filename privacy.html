Privacy Policy

Last updated: 25 September 2026

Shorts Factory Uploader ("the tool") is a private tool operated by a single creator for their own YouTube channels. It uses YouTube API Services. Use of those services is also governed by the Google Privacy Policy and the YouTube Terms of Service.

What data the tool accesses

  • An OAuth refresh token for the owner's own YouTube channel. The owner grants it with three permissions: upload videos, view the YouTube account (read-only) and manage YouTube videos.
  • The channel ID and title, to make sure videos go to the correct channel.
  • The ID, privacy status, scheduled publish time and processing status of videos that the tool itself uploaded.

The "manage YouTube videos" permission is used only to change the privacy status and the scheduled publish time of videos that the tool itself uploaded. The tool does not read or post comments. It does not access subscribers, analytics, other people's data or other channels.

How the data is used

The data is used only for these tasks:

  • upload the owner's approved videos as private videos with a scheduled publish time;
  • move that time when the owner changes the schedule;
  • publish the video at the chosen time;
  • check the video's current status.

The data is never sold, shared with third parties or used for advertising.

Storage and retention

The refresh token is stored in a private configuration file on the owner's own server and is never published. Video IDs and statuses are kept in the tool's local database for as long as the owner keeps the related project records.

This website and the tool do not place cookies and do not store any data on visitors' devices.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. After revocation the stored token stops working and the owner deletes it from the server configuration. On request, any stored video IDs and statuses are deleted within 7 days.

Contact

Questions about this policy can be sent through the support e-mail shown on the Google consent screen, or as an issue in this site's repository: github.com/Wartherio/wartherio.github.io/issues.
